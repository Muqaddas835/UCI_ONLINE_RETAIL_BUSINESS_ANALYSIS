# Dataset

This project uses the **Online Retail II** dataset from the UCI Machine Learning Repository.

🔗 Download: https://archive.ics.uci.edu/dataset/502/online+retail+ii

- Period used: 01 Dec 2009 – 09 Dec 2010
- Raw file: `online_retail_II.xlsx` (first sheet)
- Cleaned file (`online_retail_cleaned.csv`) is created by running `notebooks/online_retail_cleaning.ipynb`

The raw and cleaned data files are not stored in this repository because of their size.
